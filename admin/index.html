GitHub Token (untuk Simpan & Publish)

Token ini digunakan agar admin panel bisa menyimpan perubahan langsung ke GitHub. Token tidak disimpan permanen — hanya aktif selama sesi browser ini.

📋 Cara dapatkan token:

  1. Buka github.com/settings/tokens/new
  2. Beri nama token, misal: portfolio-admin
  3. Centang repo (full control)
  4. Scroll bawah → klik Generate token
  5. Copy token dan paste di bawah ini
